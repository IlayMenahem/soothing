\section{Branching with variable zeroing}
\label{sec:variable-zeroing}

Algorithm~\ref{alg:ZeroingBranching} handles timeouts from the branch solver.
After a timeout, it chooses a variable $x$ and replaces the unresolved branch
with two children, one with the additional constraint $x = 0$ and another with $x\neq 0$.
It then applies Algorithm~\ref{alg:Branching} recursively to both children. The recursion stops when all branches are resolved, no splitting variables remain, or the computation budget is exhausted.
This construction does not depend on the choice of branch solver.

% Pseudocode for the method with variable zeroing
\begin{algorithm}
\footnotesize
\caption{Recursive branching with variable zeroing}
\label{alg:ZeroingBranching}
\begin{algorithmic}[1]
    \Require A polynomial system $P$, and a timeout $\tau$.
    \Function{ZeroingBranching}{$P, \tau$}
        \State $C \gets \emptyset$ \Comment{One global UNSAT-core set}
        \State $X \gets \Call{Variables}{P}$ \Comment{All variables of $P$}
        \State \Return $\Call{SolveByZeroing}{P,X,\tau,C}$
    \EndFunction
    \Function{SolveByZeroing}{$P,X,\tau,C$}
        \State $(S,T) \gets \Call{BranchingWithTimeout}{P,\tau,C}$
        \Comment{Algorithm~\ref{alg:Branching}; $C$ is shared and updated}
        \State $U \gets \emptyset$ \Comment{Branches left unresolved}

        \ForAll{$Q \in T$}
            \If{$X=\emptyset$}
                \State $U \gets U\cup\{Q\}$
                \State \textbf{continue}
            \EndIf

            \State $x \gets \Call{ChooseVariable}{Q,X}$
            \State $(S_0, U_0, C) \gets \Call{SolveByZeroing}{Q\cup\{x\}, X\setminus\{x\}, \tau,C}$
            \State $(S_1, U_1, C) \gets \Call{SolveByZeroing}{Q\cup\{1-xz\}, X\setminus\{x\}, \tau,C}$
            \Comment{$z$ is fresh}

            \State $S \gets S\cup S_0\cup S_1$
            \State $U \gets U\cup U_0\cup U_1$
        \EndFor

        \State \Return $(S, U, C)$
    \EndFunction
\end{algorithmic}
\end{algorithm}

Solutions of the nonzero branch are projected onto the original variables, so the fresh variables do not appear in the output.

In the zero branch, the solver can substitute $x=0$ directly. In the nonzero
branch, $1-xz=0$ records that $x$ is invertible. Interreduction with either
equation may simplify the remaining generators. The effect depends on the
branch solver. Section~\ref{sec:experiments} describes the Gr\"obner-basis
solvers used in our experiments.

The run on \texttt{systems/system.txt}, with a five-second timeout for each
hitting set, produces the recursion tree in Figure~\ref{fig:variable_zeroing_tree}.
The variable chosen after a timeout is written inside the corresponding hitting-set
node.  Its outgoing edges give the zero and nonzero cases.

\subsection{Choice of variable for splitting}
\label{subsec:zeroing-variable-choice}

The choice of variable for splitting effects the efficiency of the algorithm.
Every split creates at least two new hitting sets to check.
If a variable barely occurs in the current hitting set, both recursive calls may repeat most of the same work.
A variable that occurs in many generators is a more promising choice: setting it to zero removes all terms containing it at once, while in the nonzero branch the algorithm can use the $1 - xz$.

For each candidate variable $x$ that is still available on the current branch, define
\begin{align*}
    g_Q(x) &= \#\{q\in Q : x\text{ occurs in }q\},\\
    t_Q(x) &= \#\{(q,m) : q\in Q,\ m\text{ is a term of }q \deg_x(m) > 0\},\\
    e_Q(x) &= \sum_{q\in Q}\ \sum_{\substack{m\text{ a term of }q \deg_x(m) > 0}} \deg_x(m).
\end{align*}
Its score is the triple
\[
    h_Q(x)=\bigl(g_Q(x),t_Q(x),e_Q(x)\bigr),
\]
and scores are compared lexicographically.

\subsection{Theoretical analysis of variable zeroing}
\label{subsec:zeroing-theoretical-analysis}

Let $Y$ be the set of variables in the input system, and let $\pi_Y$ denote
projection onto those coordinates. For any system $Q$ encountered during the
recursion, write
\[
    V_Y(Q)=\pi_Y(V(Q)).
\]
This projection removes the inverse variables introduced along the path to
$Q$.

We use the following contract for \textsc{BranchingWithTimeout}. On input $Q$,
it returns a collection $S_Q$ of solution-set representations and a set $T_Q$
of unresolved branches such that
\begin{equation}
\label{eq:timeout-decomposition}
    V_Y(Q)=\operatorname{Sol}(S_Q)\cup\bigcup_{R\in T_Q}V_Y(R).
\end{equation}
As defined in Section~\ref{sec:method}, $\operatorname{Sol}(S_Q)$ is the union
of the sets represented by $S_Q$, projected here onto the coordinates in $Y$.
Equation~\eqref{eq:timeout-decomposition} is the usual branching invariant: a
timeout moves an unprocessed branch to $T_Q$ instead of discarding it. We also
assume, as in
Theorem~\ref{thm:branching-correctness}, that every learned UNSAT core
is certified.

\begin{lemma}[Correctness of a zeroing split]
\label{lem:zeroing-split}
Let $x\in Y$, and let $z$ be a variable that does not occur in $Q$. Then
\[
    V_Y(Q)=V_Y(Q\cup\{x\})\cup V_Y(Q\cup\{1-xz\}).
\]
\end{lemma}

\begin{proof}
Take $a\in V_Y(Q)$ and choose a point $\widetilde a\in V(Q)$ with
$\pi_Y(\widetilde a)=a$. If $\widetilde a_x=0$, then
$a\in V_Y(Q\cup\{x\})$. If $\widetilde a_x\neq 0$, extend $\widetilde a$ by
setting $z=\widetilde a_x^{-1}$. The resulting point satisfies $1-xz=0$, so
$a\in V_Y(Q\cup\{1-xz\})$. This proves the forward inclusion. The reverse
inclusion follows because each child system contains every polynomial in
$Q$.
\end{proof}

\begin{theorem}[Variable zeroing]
\label{thm:zeroing-correctness}
Suppose Algorithm~\ref{alg:ZeroingBranching} returns $(S,U,C)$ on input $P$.
Then
\[
    V(P)=\operatorname{Sol}(S)\cup\bigcup_{R\in U}V_Y(R).
\]
In particular, if $U=\emptyset$, then $\operatorname{Sol}(S)=V(P)$.
\end{theorem}

\begin{proof}
We prove the stronger claim that every call
$\operatorname{SolveByZeroing}(Q,X,\tau,C)$ returning $(S',U',C')$ satisfies
\begin{equation}
\label{eq:zeroing-invariant}
    V_Y(Q)=\operatorname{Sol}(S')\cup\bigcup_{R\in U'}V_Y(R).
\end{equation}
The proof is by induction on $|X|$.

If $X=\emptyset$, the procedure cannot split an unresolved branch.
It returns the representations found by
\textnormal{\textsc{BranchingWithTimeout}} and places every branch in $T_Q$
into $U'$. Thus, Equation~\eqref{eq:zeroing-invariant} is exactly
Equation~\eqref{eq:timeout-decomposition}.

Now suppose $X\neq\emptyset$ and that the claim holds whenever fewer
variables are available. Let $(S_Q,T_Q)$ be the result of
\textnormal{\textsc{BranchingWithTimeout}} on $Q$. For each $R\in T_Q$, the
procedure chooses some $x\in X$ and recursively processes
\[
    R_0=R\cup\{x\}
    \qquad\text{and}\qquad
    R_1=R\cup\{1-xz\},
\]
where $z$ is fresh. Both calls use the smaller set $X\setminus\{x\}$.
Lemma~\ref{lem:zeroing-split} gives
\[
    V_Y(R)=V_Y(R_0)\cup V_Y(R_1).
\]
Substituting these decompositions into
Equation~\eqref{eq:timeout-decomposition} gives
Equation~\eqref{eq:zeroing-invariant}.

Apply the claim to the initial call with $Q=P$. Since $P$ contains no inverse
variables, $V_Y(P)=V(P)$, which proves the stated identity. If $U$ is empty,
the union over $U$ is empty and hence $\operatorname{Sol}(S)=V(P)$.
\end{proof}

Now to show the run always terminates in finite time.
\begin{theorem}
    \label{thm:zeroing-termination}
    Zeroing-Branching~\ref{alg:ZeroingBranching} terminates in finite time.
\end{theorem}
\begin{proof}
    The depth of the recursion tree is at most $|X|$ since for each call an unused variable is required and removed.
    The branching factor is bounded by the number of hitting sets of factors which is finite.
    The tree size is finite, and due to the timeout each hitting set is evaluated in finite time.
    Thus the algorithm terminates in finite time.
\end{proof}

We can infer a solution-set representation for the hitting set on which the solver timed out from its children's representations.
If all children are UNSAT, then so is the result of the timeout evaluation.
Otherwise it represents the union of the sets represented by its children.
