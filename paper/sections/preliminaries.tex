\label{sec:preliminaries}

\subsection{Notation}

Let $K$ be a field, let $\overline{K}$ be an algebraic closure of $K$, and let
$K[x_1,\ldots,x_n]$ be the polynomial ring in $n$ variables over $K$. We write
the input system as
\[
    P = \{p_1,\ldots,p_m\} \subseteq K[x_1,\ldots,x_n].
\]
We assume that each $p_i$ is nonzero and fix a factorization
\[
    p_i = a_i \prod_{f \in C_i} f^{e_{i,f}},
\]
where $a_i \in K \setminus \{0\}$, $C_i$ is the set of distinct nonconstant
factors appearing in the factorization, and $e_{i,f} \geq 1$ is the
multiplicity of $f$.

For any set of polynomials $Q \subseteq K[x_1,\ldots,x_n]$, we write
$\langle Q\rangle$ for the ideal generated by $Q$ and define its zero set over
the algebraic closure by
\[
    V(Q) = \{x \in \overline{K}^{n} : q(x) = 0
    \text{ for every } q \in Q\}.
\]
For $X\subseteq\overline{K}^{n}$, its vanishing ideal is
\[
    I(X)=\{g\in K[x_1,\ldots,x_n] : g(x)=0
    \text{ for every }x\in X\}.
\]
Unless stated otherwise, satisfiability refers to solutions over
$\overline{K}$. Hilbert's Nullstellensatz~\cite{cox2015ideals} gives
\[
    V(Q)=\emptyset
    \quad\Longleftrightarrow\quad
    \langle Q\rangle=\langle 1\rangle.
\]
Equivalently, the reduced Gr\"obner basis of $\langle Q\rangle$ is $\{1\}$.
A set $U \subseteq Q$ is an unsatisfiable core of $Q$ if $V(U)=\emptyset$.

A hitting set of $C_1,\ldots,C_m$ is a set
$H \subseteq \bigcup_{i=1}^m C_i$ such that $H \cap C_i \neq \emptyset$ for
every $i$. It is minimal if none of its proper subsets is also a hitting set.
We denote the collection of all minimal hitting sets of
$C_1,\ldots,C_m$ by $\mathcal{H}$.
