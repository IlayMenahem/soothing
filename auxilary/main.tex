\section{Introduction}

A Gr\"obner basis is the standard tool for solving a system of multivariate polynomial equations $p_1 = \cdots = p_m = 0$: from it one can describe the solution set, eliminate variables, and decide ideal membership. Computing one, however, has doubly exponential worst-case complexity, and in practice becomes infeasible as the number of variables or the polynomial degrees grow.

For some problems we only need a Gr\"obner basis of a \emph{subvariety} of the variety $V(p_1, \ldots, p_m)$ --- a subset of the solutions that is cheaper to describe. We obtain such a subvariety by zeroing a chosen set of variables and selecting one irreducible factor of each polynomial, which replaces the original system with a smaller, often triangular one whose Gr\"obner basis is tractable. Every point of the subvariety is a genuine solution of the original system, so the output is sound; what we forgo is completeness, as solutions outside the subvariety are not recovered. This lets the method solve some systems that are out of reach for the standard algorithms.

The main drawback is that the subvariety may have much smaller dimension than the original variety. We show (Claim~2) that this loss comes only from the zeroed variables, not from factor selection, so the framework can target a subvariety of maximal dimension among those reachable by factor selection. The rest of the document formalizes the framework and its soundness (Section~2), gives a mixed-integer linear program that chooses the variables to zero, the factors, and a compatible variable order (Section~3), and explains how to measure the dimension of the solution set actually obtained (Section~4).

\section{Framework}
The framework specifies methods for finding the Gr\"obner basis of a subvariety of the variety generated by a set of multivariate polynomials. The idea is to cut the system down before computing anything: zeroing variables removes them from every polynomial, and factoring lets us replace each polynomial $p'_j$ by a single irreducible factor, a weaker equation whose zero locus lies inside $V(p'_j)$. Both operations shrink the variety to a subvariety while leaving a smaller, more tractable system.

Given a set of multivariate polynomials $p_1, \ldots, p_m$, we perform the following preprocessing:
\begin{enumerate}
    \item Select a subset of the variables to be zeroed, and substitute $0$ for those variables in the polynomials.
    \item (optional) Interreduce the polynomials with respect to a lexicographic order (using a min-fill heuristic variable ordering) to obtain new polynomials $p'_1, \ldots, p'_{m}$, and discard any zero polynomials.
    \item Find the factorization of each polynomial into
    \[
        \bigl\{\,(f,\;\{p'_j \mid f \text{ appears in } p'_j\})\;\bigm|\; f \text{ is an irreducible factor of at least one polynomial}\,\bigr\}.
    \]
    \item Select a subset of the variables to be zeroed, and substitute $0$ for those variables in the polynomials.
    \item Choose one factor for each $p'_j$ together with a lexicographic order, and compute the Gr\"obner basis of the selected factors.
\end{enumerate}
Zeroing appears twice, in steps~1 and~4, because the two are useful at different stages: zeroing before interreduction and factoring (step~1) can simplify the polynomials and expose better factorizations, while zeroing afterwards (step~4) can be chosen with the factorization in hand to make the Gr\"obner basis of the selected factors easier to compute. Either step may be empty.

\begin{claim}
The resulting Gr\"obner basis is a Gr\"obner basis of an ideal whose variety is a subvariety of the original variety.
\end{claim}
\begin{proof}
Let $I = \langle p_1, \ldots, p_m \rangle \subseteq k[x_1, \ldots, x_n]$ be the original ideal, write $Z = Z_1 \cup Z_2$ for the union of variables zeroed in steps~1 and~4, and let $V(Z) = \{a \in k^n : a_v = 0 \text{ for all } v \in Z\}$. Denote the Gr\"obner basis produced in step~5 by $G$, and set $J = \langle G \rangle + \langle v : v \in Z \rangle$. It suffices to show $V(J) \subseteq V(I)$.

\emph{Steps~1 and~4 (zeroing).} For any polynomial $q$ and variable set $W$, the substitution $q|_{W=0}$ agrees with $q$ on $V(W)$, so $V(q|_{W=0}) \cap V(W) = V(q) \cap V(W)$. Writing $\tilde p_j = p_j|_{Z_1=0}$ and $p''_j = p'_j|_{Z_2=0}$, applying this generator-wise gives
\[
    V(\tilde p_1, \ldots, \tilde p_m) \cap V(Z_1) = V(I) \cap V(Z_1),
    \qquad
    V(p''_1, \ldots, p''_m) \cap V(Z_2) = V(p'_1, \ldots, p'_m) \cap V(Z_2).
\]

\emph{Step~2 (interreduction).} Each interreduction step replaces a generator $\tilde p_i$ with $\tilde p_i - h \tilde p_j$ for some $h \in k[x_1, \ldots, x_n]$. Since $\tilde p_i = (\tilde p_i - h \tilde p_j) + h \tilde p_j$, the ideal is preserved, so $\langle p'_1, \ldots, p'_m \rangle = \langle \tilde p_1, \ldots, \tilde p_m \rangle$ and $V(p'_1, \ldots, p'_m) = V(\tilde p_1, \ldots, \tilde p_m)$.

\emph{Step~3 (factorization).} This records the irreducible factors and does not change the ideal.

\emph{Step~5 (factor selection).} For each $j$, the chosen factor (which, after the Step~4 zeroing, we denote $f_j = f_{j,i_j}|_{Z_2=0}$) divides $p''_j$, so $V(f_j) \subseteq V(p''_j)$, and intersecting over $j$,
\[
    V(f_1, \ldots, f_m) = \bigcap_j V(f_j) \subseteq \bigcap_j V(p''_j) = V(p''_1, \ldots, p''_m).
\]
Computing a Gr\"obner basis preserves the ideal, so $\langle G \rangle = \langle f_1, \ldots, f_m \rangle$.

\emph{Combining.} Chaining the inclusions,
\[
    V(J) = V(\langle G \rangle) \cap V(Z)
    \subseteq V(p''_1, \ldots, p''_m) \cap V(Z)
    = V(p'_1, \ldots, p'_m) \cap V(Z)
    = V(\tilde p_1, \ldots, \tilde p_m) \cap V(Z)
    = V(I) \cap V(Z)
    \subseteq V(I).
\]
Hence $G$ is a Gr\"obner basis of the ideal $J$, whose variety is a subvariety of $V(I)$.
\end{proof}

It is worth noting that selecting one factor of each preprocessed polynomial does not reduce the dimension of the solution set; only the choice of which variables to zero does. This idea is formalized in the following claim.
\begin{claim}
Selecting one irreducible factor of each preprocessed polynomial does not reduce the dimension of the solution set, provided the factors are chosen jointly so as to realize a maximal-dimension intersection.
\end{claim}
\begin{proof}
Each preprocessed polynomial factors as $p'_j = \prod_i f_{j,i}$, so its zero locus decomposes as $V(p'_j) = \bigcup_i V(f_{j,i})$. Intersecting over $j$ distributes the union:
\[
    V(p'_1, \ldots, p'_m) = \bigcup_{(i_1, \ldots, i_m)} V(f_{1,i_1}) \cap \cdots \cap V(f_{m, i_m}).
\]
The dimension of a finite union is the maximum of the dimensions of its members, so
\[
    \dim V(p'_1, \ldots, p'_m) = \max_{(i_1, \ldots, i_m)} \dim\bigl(V(f_{1,i_1}) \cap \cdots \cap V(f_{m, i_m})\bigr).
\]
A branch realizing this maximum is obtained by jointly selecting factors $f_{1, i_1}, \ldots, f_{m, i_m}$ whose common vanishing locus has maximal dimension.
\end{proof}

\section{A method for selecting variables to zero, factors, and a lexicographic order}

Suppose we do not zero any variables in the first preprocessing step.
We seek tuples $(f_1, x_1), \ldots, (f_k, x_k)$ and variables to zero $v_1, \ldots, v_l$ that let us construct a \emph{triangular set}.

A triangular set is a system whose equations can be ordered $f_1 = 0, \ldots, f_k = 0$ so that each $f_i$ introduces its own variable $x_i$, with $x_i$ depending only on variables introduced earlier.

Such a system can be solved by back-substitution: solve $f_1$ for $x_1$, substitute into $f_2$ and solve for $x_2$, and so on.

The three conditions below guarantee that the selected factors form a triangular set: \textbf{Coverage} ensures every polynomial is accounted for, \textbf{Non-degenerate definer} that each $f_i$ genuinely constrains its variable $x_i$, and \textbf{Acyclicity} that the ``depends on'' relation admits a consistent ordering.
\begin{enumerate}
    \item \textbf{Coverage.} Each polynomial $p$ must either contain a factor that appears in some tuple $(f_i, x_i)$, or become identically zero after zeroing the variables in $Z$.
    \item \textbf{Non-degenerate definer.} For each $x_i$, after zeroing the variables in $Z$, $f_i$ must have positive degree in $x_i$.
    \item \textbf{Acyclicity.} The dependency graph $G = (\{x_1,\ldots,x_k\}, E)$ with
    \[
        E = \{(x_j, x_i) \mid j \neq i \text{ and } x_j \text{ appears in } f_i\}
    \]
    is acyclic.
\end{enumerate}

We formulate the fulfilment of these conditions as a mixed-integer linear program (MILP).

\subsection{Notation}

Let $P$ be the set of preprocessed polynomials, $F$ the set of factors, and $V$ the set of variables. For $p \in P$, let $F_p \subseteq F$ be the factors of $p$. For $f \in F$, let $\mathrm{mon}(f)$ be its monomials and $\mathrm{vars}(f) \subseteq V$ the variables appearing in $f$. For a monomial $m$, let $\mathrm{vars}(m)$ be its variables and $\deg_x(m)$ its degree in $x$. Let
\[
    M^{\ge 1}_{f,x} = \{m \in \mathrm{mon}(f) : \deg_x(m) \ge 1\}.
\]

\subsection{Worked example}

Take $V = \{x_1, x_2, x_3, x_4\}$ over a field $k$, skip the first zeroing and the interreduction, and start from the system
\[
\begin{aligned}
    p_1 &= (x_1 - 1)(x_1 + 1), &\qquad
    p_2 &= (x_2 - x_1)(x_2 + x_1 + 1), \\
    p_3 &= (x_3 - x_1 x_2)\, x_4, &\qquad
    p_4 &= x_4\,(x_1 + x_2 + x_3 + 1).
\end{aligned}
\]
Step~3 records the irreducible factors; the factor $x_4$ is shared by $p_3$ and $p_4$:
\[
    F = \{\, x_1 - 1,\; x_1 + 1,\; x_2 - x_1,\; x_2 + x_1 + 1,\; x_3 - x_1 x_2,\; x_4,\; x_1 + x_2 + x_3 + 1 \,\}.
\]
The factor $x_4$ is a single monomial, so it cannot define a variable: the equation $x_4 = 0$ pins down no particular variable to solve for. It can still be used by zeroing $x_4$.

\paragraph{Selection.} Zero $Z = \{x_4\}$ and select the tuples
\[
    (x_1 - 1,\; x_1), \qquad (x_2 - x_1,\; x_2),
\]
leaving $x_3$ free.

\paragraph{Conditions.} The selection satisfies the three conditions of Section~3.
\begin{itemize}
    \item \textbf{Coverage.} $p_1$ contains the selected factor $x_1 - 1$ and $p_2$ contains $x_2 - x_1$. Both $p_3$ and $p_4$ contain the factor $x_4$, which becomes identically zero after zeroing $x_4$.
    \item \textbf{Non-degenerate definer.} After zeroing $x_4$, the factor $x_1 - 1$ has positive degree in $x_1$ and $x_2 - x_1$ has positive degree in $x_2$.
    \item \textbf{Acyclicity.} The dependency graph has the single edge $x_1 \to x_2$ (from $x_1 \in \mathrm{vars}(x_2 - x_1)$), which is acyclic; the order $x_2 > x_1$ is consistent with it.
\end{itemize}

    x_1 - 1 = 0, \qquad x_2 - x_1 = 0
\]

\subsection{Variables}

\textbf{Decision variables:}
\begin{itemize}
    \item $s_{f, x} \in \{0, 1\}$ for each $(f, x) \in F \times V$. $s_{f, x} = 1$ iff the factor $f$ is selected as the algebraic definer of the variable $x$.
    \item $z_v \in \{0, 1\}$ for each $v \in V$. $z_v = 1$ iff the variable $v$ is zeroed.
\end{itemize}

\textbf{Auxiliary indicator variables} (continuous in $[0, 1]$; pinned to $\{0,1\}$ by the constraints below):
\begin{itemize}
    \item $\zeta_f \in [0, 1]$ for each $f \in F$. $\zeta_f = 1$ iff $f$ becomes identically zero after zeroing $\{v : z_v = 1\}$.
    \item $y_p \in [0, 1]$ for each $p \in P$. $y_p = 1$ iff $p$ becomes identically zero after zeroing.
    \item $a_{f, x, m} \in [0, 1]$ for each $(f, x) \in F \times V$ and each $m \in M^{\ge 1}_{f, x}$. $a_{f, x, m} = 1$ indicates that monomial $m$ (which has positive degree in $x$) survives the zeroing.
    \item $t_x \in [0, |V|]$ for each $x \in V$. Topological position of $x$, used to enforce acyclicity.
\end{itemize}

\subsection{Factor-Zeroing Definition}

A factor $f$ is identically zero after zeroing iff every monomial of $f$ contains at least one zeroed variable. Encoded as, for each $f \in F$ and each $m \in \mathrm{mon}(f)$:
\[
    \zeta_f \le \sum_{v \in \mathrm{vars}(m)} z_v.
\]
(Maximization in the objective drives $\zeta_f$ to its upper bound, which is $1$ exactly when every monomial has a zeroed variable.)

\subsection{Constraints}

\textbf{(C1) Coverage.} Every preprocessed polynomial $p \in P$ must have either a factor that is selected as an algebraic definer for some variable, or a factor that becomes identically zero after zeroing:
\[
    \sum_{f \in F_p} \left( \zeta_f + \sum_{x \in V} s_{f, x} \right) \ge 1 \qquad \forall\, p \in P.
\]

\textbf{(C2) Non-degenerate definer.} For each selected pair $(f, x)$, after zeroing, $f$ must have positive degree in $x$: at least one monomial of $f$ of positive degree in $x$ must survive.

\begin{itemize}
    \item[(C2a)] A monomial $m \in M^{\ge 1}_{f, x}$ survives only if none of its non-$x$ variables are zeroed. For each $(f, x) \in F \times V$, each $m \in M^{\ge 1}_{f, x}$, and each $v \in \mathrm{vars}(m) \setminus \{x\}$:
    \[
        a_{f, x, m} \le 1 - z_v.
    \]
    \item[(C2b)] If $f$ is selected for $x$, at least one monomial of positive degree in $x$ must survive. For each $(f, x) \in F \times V$:
    \[
        s_{f, x} \le \sum_{m \in M^{\ge 1}_{f, x}} a_{f, x, m}.
    \]
    (If $M^{\ge 1}_{f, x} = \emptyset$ --- including the case $x \notin \mathrm{vars}(f)$ --- this forces $s_{f, x} = 0$.)
\end{itemize}

\textbf{(C3) Acyclicity.} Use a topological-order encoding on the potential vertices. For each $(f, x) \in F \times V$ and each $x' \in \mathrm{vars}(f) \setminus \{x\}$:
\[
    t_{x'} + 1 \le t_x + (|V| + 1)\,(1 - s_{f, x}).
\]
When $s_{f, x} = 1$ this enforces $t_{x'} < t_x$ on every potential predecessor edge $x' \to x$ of the dependency graph; when $s_{f, x} = 0$ the big-$M$ term deactivates the constraint. A consistent assignment of $\{t_x\}$ exists iff the induced graph on the selected variables is acyclic.

\textbf{(C4) Pairwise distinct.} No variable is both selected (as some $x_i$) and zeroed (as some $v_j$), and each variable is selected at most once. For each $x \in V$:
\[
    \sum_{f \in F} s_{f, x} + z_x \le 1.
\]

\textbf{(C5) Monomial factors.} A factor $f$ with $|\mathrm{mon}(f)| = 1$ (i.e.\ $f$ is a single monomial) cannot algebraically define any variable: the equation $f = 0$ merely forces some variable in the product to zero but does not single out any one variable. Therefore:
\[
    s_{f, x} = 0 \qquad \forall\, x \in V, \text{ whenever } |\mathrm{mon}(f)| = 1.
\]
In practice, such factors are excluded from the admissible set entirely, so no $s_{f,x}$ variable is ever created for them.

\subsection{Objective}

A polynomial is zeroed iff at least one of its factors is, so for each $p \in P$,
\[
    y_p \le \sum_{f \in F_p} \zeta_f.
\]

Maximize the number of zeroed polynomials, breaking ties by maximizing the number of \emph{free} variables --- those neither selected nor zeroed. Setting $\varepsilon = \frac{1}{|V|+1}$ keeps the tiebreaker bounded by $|V|\varepsilon < 1$, so it never overrides a unit difference in the primary term:
\[
    \max \; \sum_{p \in P} y_p \;-\; \varepsilon\!\left(\sum_{(f,x)} s_{f,x} + \sum_{v \in V} z_v\right).
\]

\section{Measuring Capability}

If the method finds tuples $(f_1, x_1), \ldots, (f_k, x_k)$ and variables to zero $v_1, \ldots, v_l$ that satisfy the conditions, we can take a point $p$ in the solution set and compute the dimension of the solution set as
\[
    \#\text{variables} - \operatorname{rank}\bigl(J_p\bigr),
\]
where $J_p$ is the Jacobian of the full system $p_1, \ldots, p_m$ at $p$. A witness point $p$ can be obtained from the triangular set $\{f_1, \ldots, f_k\}$ (after substituting $v_j = 0$), by numerical homotopy or regular-chain real-root isolation; closed-form radical evaluation of the $x_i$ is not required.

\section{CDCL for system of polynomial equations}

Let us say we have a set of factored polynomials $p_1, \ldots, p_m$ over a field $k$, and we want to validate whether there exists a solution to the system $p_1 = \cdots = p_m = 0$ (or any other property that can be inferred from the minimal hitting sets).
We describe a CDCL-style algorithm that can be used to explore the space of possible minimal hitting sets of the polynomials.

\begin{algorithm}
\caption{CDCL for Polynomial Systems}
\label{alg:cdcl}
\begin{algorithmic}[1]
    \Require A set of polynomials $p_1, \ldots, p_m$ over a field $k$.

    \State Preprocess the polynomials
    \State Factor the polynomials into irreducible factors
    \State Initialize $C = \emptyset$ an unsatisfiable cores set
    \State $S = \emptyset$

    \For{each minimal hitting set $F$ of the polynomials}
        \If{The minimal hitting set $F$ contains an unsatisfiable core in $C$}
            \State \textbf{continue} to the next minimal hitting set
        \EndIf

        \State Check if the minimal hitting set $F$ is satisfiable
        \If{The minimal hitting set $F$ is satisfiable}
            \State Add the solution to the solutions set $S$
        \Else
            \State Extract a minimal unsatisfiable core $U$ from the minimal hitting set $F$
            \State Add $U$ to the unsatisfiable cores set $C$
        \EndIf
    \EndFor

    \Return the solutions set $S$ and the unsatisfiable cores set $C$

\end{algorithmic}
\end{algorithm}

A \emph{minimal hitting set} is a set $F$ of factors that hits every polynomial: for each $p_j = \prod_i f_{j,i}$ at least one of its factors $f_{j,i}$ lies in $F$. Committing to $F$ imposes the subsystem $\{f = 0 : f \in F\}$, whose variety $V(F) = \bigcap_{f \in F} V(f)$ lies inside $V(p_1, \ldots, p_m)$ (Claim~1); minimality means no proper subset of $F$ hits every polynomial.

The order of iteration over the minimal hitting sets is from the simplest to the most complex to check for satisfiability. As a heuristic for this cost we use the B\'ezout bound $\prod_{f \in F} \deg f$: it bounds the number of isolated solutions and, for a regular cover, the solving degree of the Gr\"obner computation that decides satisfiability, whose Macaulay matrix grows with that degree. Iterating covers by increasing B\'ezout bound therefore tries the easy covers first.
