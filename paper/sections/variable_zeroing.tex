\section{Recursive splitting}
\label{sec:variable-zeroing}

\subsection{Factor branching with variable zeroing}
\label{subsec:zeroing-branching}

% Motivation for splitting
Suppose the solver does not terminate within a reasonable amount of time on a
branch produced by Algorithm~\ref{alg:Branching}.

% What is splitting
Then we can further simplify the system by recursive splitting. In each child
branch, we assume a side condition and run Algorithm~\ref{alg:Branching} on the
simplified system. This process continues until every branch is solved or a
global time budget is exhausted.

% Good properties for conditions on the set of conditions
For completeness, the side conditions must cover all possibilities. They
should also simplify the system for the solver input and work well with
Algorithm~\ref{alg:Refine}.

% What is the condition we use, and why?
In this work, we use \emph{variable zeroing}: recursive splitting with the
side conditions $x=0$ and $x\neq0$ for a selected variable $x$. Setting $x=0$
deletes every monomial containing $x$, which can make generators factor and
so create new hitting sets. Requiring $x\neq0$ removes the components of the
branch that lie in $\{x=0\}$, and we impose it by saturating the branch by
$x$.

% Pseudocode for the method with variable zeroing
\begin{algorithm}[htbp]
\small
\caption{Factor branching with variable zeroing}
\label{alg:ZeroingBranching}
\begin{algorithmic}[1]
    \Require A polynomial system $P$, a branch solver $\mathcal B$, a per-call timeout $\tau$, and a global budget $\beta$
    \State $S\gets\emptyset$; $U\gets\emptyset$ \Comment{Solved and unresolved branches}
    \State $W\gets\{(P,\emptyset,\emptyset)\}$ \Comment{Pending branches $(Q,Z,N)$}
    \While{$W\neq\emptyset$}
        \State Remove an element $(Q,Z,N)$ from $W$
        \ForAll{$H\in\Call{Refine}{Q,N}$}
            \State Run $\mathcal B$ on $(H,N)$ for at most $\tau$, unless $\beta$ is exhausted
            \State $V\gets \operatorname{vars}(H)\setminus(Z\cup N)$ \Comment{Useful variables for $H$}
            \If{$\mathcal B$ returns a representation of $V(H)\setminus V(u_N)$}
                \State Add the representation, with $(Z,N)$, to $S$
            \ElsIf{$\beta$ is exhausted or $V=\emptyset$}
                \State $U\gets U\cup\{(H,Z,N)\}$
            \Else
                \State $x\gets\Call{ChooseVariable}{H,V}$
                \State $W\gets W\cup\{(H|_{x=0},Z\cup\{x\},N)\}$ \Comment{$x=0$}
                \State $W\gets W\cup\{(\Call{Saturate}{H,N\cup\{x\}},Z,N\cup\{x\})\}$ \Comment{$x\neq0$}
            \EndIf
        \EndFor
    \EndWhile
    \State \Return $(S,U)$
\end{algorithmic}
\end{algorithm}


% How the constraints are encoded into the system.
Each pending branch $(Q,Z,N)$ records the variables $Z$ set to zero and the
variables $N$ declared nonzero on its path. Its generators lie in
$K[Y\setminus Z]$, where $Y=\operatorname{vars}(P)$, so no branch has an
auxiliary variable. With $u_N=\prod_{y\in N}y$, the points of the branch are
those of $V(Q)\setminus V(u_N)$, the solutions of $Q$ on which every variable
in $N$ is nonzero.

% Saturation
$\Call{Saturate}{H,N}$ returns a Gr\"obner basis of the saturation
$\langle H\rangle:u_N^\infty$. Every $g\in\langle H\rangle:u_N^\infty$
satisfies $u_N^mg\in\langle H\rangle$ for some $m$, so $g$ vanishes on
$V(H)\setminus V(u_N)$, and $\langle H\rangle$ lies in the saturation. Hence
\[
    V\bigl(\Call{Saturate}{H,N}\bigr)\setminus V(u_N)=V(H)\setminus V(u_N).
\]
Saturation discards the components of $V(H)$ that lie in $V(u_N)$, and the
saturated generators can factor again in the next refinement. A saturation
equal to $\langle1\rangle$ certifies the branch UNSAT. We compute the
saturation with Singular's \texttt{sat} within the per-call timeout $\tau$. If
it does not finish, $\Call{Saturate}{H,N}$ returns $H$, which satisfies the
same identity.

% Refinement and the branch solver under the nonzero conditions
Refinement and the branch solver take $N$ into account.
$\Call{Refine}{Q,N}$ removes the variables in $N$ from every factor set, since
a hitting set containing $y\in N$ has no point with $y\neq0$. It also drops a
branch once some $y\in N$ reduces to zero modulo its generators. Neither step
removes a point of $V(Q)\setminus V(u_N)$. The branch solver receives $(H,N)$
and either represents $V(H)\setminus V(u_N)$ or certifies that it is empty.
Our Gr\"obner-basis solvers add the separate Rabinowitsch generators
$\sigma_y$, $y\in N$, of Subsection~\ref{subsec:nonzero-encoding}, and
project the solutions onto the original variables. Auxiliary variables
therefore appear only inside solver calls. The zero and nonzero decisions
remain part of the solution-set representation.

For comparison, we repeat the experiment twice: once with the fixed side
conditions $x=1$ and $x\neq1$, and once with each split independently drawing
an integer $a$ uniformly from $\{-10,\ldots,10\}$ and using the side conditions
$x=a$ and $x\neq a$, saturating the branch $x\neq a$ by $x-a$. Both runs use
M4GB with a five-second limit per branch
and a ten-minute wall-clock limit. Neither alternative finishes within ten
minutes, and both searches reach depth 22, where every variable has been
split. The run with $x=1$ ends with 24 unresolved branches after 73 splits,
and the run with random values, seeded with $0$, ends with 29 after 89
splits.

On this system, zero/nonzero splits are therefore more effective than these
affine splits.

\subsection{Choice of variable for splitting}
\label{subsec:zeroing-variable-choice}

The choice of variable for splitting affects the efficiency of the algorithm.
If a variable barely occurs in the current branch, its child branches may
repeat the same work. A variable that occurs in many generators is a more
promising choice. Setting it to zero removes all terms containing it at once.
In the nonzero branch, saturation by $x$ discards every component on which
$x$ vanishes.

For each $x\in X = \operatorname{vars}(Q)\setminus(Z\cup N)$, the variables not yet split on, define
\begin{align*}
    g_Q(x) &= \#\{q\in Q : x\text{ occurs in }q\},\\
    t_Q(x) &= \#\{(q,m) : q\in Q,\ m\text{ is a term of }q,\ \deg_x(m) > 0\},\\
    e_Q(x) &= \sum_{q\in Q}\ \sum_{\substack{m\text{ a term of }q,\\ \deg_x(m) > 0}} \deg_x(m).
\end{align*}
Its score is the triple
\[
    h_Q(x)=\bigl(g_Q(x),t_Q(x),e_Q(x)\bigr),
\]
and scores are compared lexicographically.
$\mathrm{ChooseVariable}(Q,X)$ returns a variable $x\in X$ with the largest score $h_Q(x)$.

\subsection{Branch contraction}
\label{subsec:zeroing-branch-contraction}

Suppose that one child of a split on $x$ has no terminal branches (i.e., UNSAT) and the other has exactly one, $H$.
Lemma~\ref{lem:recursive-refinement} and Equation~\eqref{eq:zeroing-split} give
\[
    V_Y(Q;Z,N)=
    \begin{cases}
        V_Y(H;Z,N\cup\{x\}) & \text{if the $x=0$ child is UNSAT,}\\
        V_Y(H;Z\cup\{x\},N) & \text{if the $x\neq0$ child is UNSAT.}
    \end{cases}
\]
Thus we can choose the next splitting variable without running the branch solver on $H$, or losing solutions.
This optimization may save a solver call that is likely to fail.

\subsection{Theoretical analysis}
\label{subsec:zeroing-theoretical-analysis}

The correctness argument uses only that the side conditions cover all
possibilities. Let $Y=\operatorname{vars}(P)$ be the original variables, let
$A$ be the conditions on the current branch, and let $V_Y(Q;A)$ be the set of
points of $\overline K^{Y}$ that satisfy $A$ and solve $Q$. For variable
zeroing, a pending branch $(Q,Z,N)$ has $Q\subseteq K[Y\setminus Z]$, and we
write
\[
    V_Y(Q;Z,N)=\bigl\{a\in\overline K^{Y}:
    a_z=0\ (z\in Z),\ a_y\neq0\ (y\in N),\
    a|_{Y\setminus Z}\in V(Q)\bigr\}.
\]
At the root, $V_Y(P;\emptyset,\emptyset)=V(P)$. If side conditions
$D_1,\ldots,D_k$ cover every point satisfying $A$, and each child $Q_i$ has
exactly the points of $V_Y(Q;A)$ that satisfy $D_i$, then $V_Y(Q;A)$ is the
union of the sets $V_Y(Q_i;A\cup\{D_i\})$.

For variable zeroing, the conditions $x=0$ and $x\neq0$ cover all values of
$x$. Lemma~\ref{lem:zero-nonzero-split} is a set-theoretic form of the
decomposition $V(I)=V(I+\langle f\rangle)\cup V(I:f^\infty)$~\cite[Ch.~4, \S4]{cox2015ideals}, whose ideal form is Lemma~\ref{lem:saturation-split}.

\begin{lemma}
\label{lem:zero-nonzero-split}
Let $H$ be a terminal branch of a pending branch $(Q,Z,N)$, let
$Q_0=H|_{x=0}$, and let $Q_1=\Call{Saturate}{H,N\cup\{x\}}$. Then
\begin{equation}
\label{eq:zeroing-split}
    V_Y(H;Z,N)=V_Y(Q_0;Z\cup\{x\},N)
    \cup V_Y(Q_1;Z,N\cup\{x\}).
\end{equation}
\end{lemma}

\begin{proof}
Every point has $a_x=0$ or $a_x\neq0$, so by the covering argument above it
suffices to show that $V_Y(Q_0;Z\cup\{x\},N)$ and $V_Y(Q_1;Z,N\cup\{x\})$
consist of the points of $V_Y(H;Z,N)$ with $a_x=0$ and with $a_x\neq0$,
respectively. At a point with $a_x=0$, each $q|_{x=0}$ takes the value of
$q$, which gives the first set. The
identity
$V\bigl(\Call{Saturate}{H,N\cup\{x\}}\bigr)\setminus V(u_{N\cup\{x\}})
=V(H)\setminus V(u_{N\cup\{x\}})$ of
Subsection~\ref{subsec:zeroing-branching} gives the second.
\end{proof}

Let $\mathcal L(Q,N)$ be the terminal branches returned by
$\Call{Refine}{Q,N}$. Lemma~\ref{lem:recursive-refinement}, applied in the ring
of $Q$, and the two steps that use $N$ keep every point of
$V(Q)\setminus V(u_N)$, so
$V(Q)\setminus V(u_N)=\bigcup_{H\in\mathcal L(Q,N)}V(H)\setminus V(u_N)$.
Since $V_Y(Q;Z,N)$ depends on $Q$ only through $V(Q)\setminus V(u_N)$,
\begin{equation}
\label{eq:zeroing-refinement}
    V_Y(Q;Z,N)=\bigcup_{H\in\mathcal L(Q,N)}V_Y(H;Z,N).
\end{equation}

\begin{theorem}[Correctness of recursive splitting]
\label{thm:zeroing-correctness}
Suppose every split uses side conditions that cover all possibilities. If
Algorithm~\ref{alg:ZeroingBranching} returns $(S,U)$ on input $P$, then
\[
    V(P)=\operatorname{Sol}(S)
    \cup\bigcup_{(H,Z,N)\in U}V_Y(H;Z,N),
\]
where a representation in $S$ stored with $(Z,N)$ for the branch $H$
represents $V_Y(H;Z,N)$.
\end{theorem}

\begin{proof}
The algorithm maintains
\[
    V(P)=\operatorname{Sol}(S)
    \cup\bigcup_{(H,Z,N)\in U}V_Y(H;Z,N)
    \cup\bigcup_{(Q,Z,N)\in W}V_Y(Q;Z,N),
\]
which holds initially, since $V_Y(P;\emptyset,\emptyset)=V(P)$. An iteration
removes $(Q,Z,N)$ from $W$, and Equation~\eqref{eq:zeroing-refinement}
replaces $V_Y(Q;Z,N)$ by the sets $V_Y(H;Z,N)$ of its terminal branches. The
algorithm then represents $V_Y(H;Z,N)$ in $S$, finds it empty, records it in
$U$, or replaces it by the sets of the two children, which have the same
union by Lemma~\ref{lem:zero-nonzero-split}, or by the covering argument for
other side conditions. So the invariant still holds, and when the algorithm
returns, $W=\emptyset$.
\end{proof}

\begin{corollary}[Completeness of variable zeroing]
\label{cor:zeroing-completeness}
If $U=\emptyset$ in the output of Algorithm~\ref{alg:ZeroingBranching}, then
$\operatorname{Sol}(S)=V(P)$.
\end{corollary}

\begin{proof}
This is Theorem~\ref{thm:zeroing-correctness} with $U=\emptyset$.
\end{proof}

The \emph{split tree} of a run of Algorithm~\ref{alg:ZeroingBranching} has
the terminal branches on which the algorithm runs $\mathcal B$ as its nodes.
The children of a branch that the algorithm splits are the terminal branches
of the two pending branches that the split creates. The leaves are the
branches that the algorithm adds to $S$ or $U$.

\begin{theorem}[Termination of recursive splitting]
\label{thm:zeroing-termination}
If $\mathcal B$ stops within the per-call timeout $\tau$ on every leaf of the
split tree, Algorithm~\ref{alg:ZeroingBranching} terminates.
\end{theorem}

\begin{proof}
Every iteration of the while loop is finite. The proof of
Theorem~\ref{thm:refine-termination} applies to $\Call{Refine}{Q,N}$: its
children are still hitting sets of factor sets, which have lost only
variables of $N$, so a child that equals its interreduced parent is still
terminal, and dropping a branch only removes children. So $\mathcal L(Q,N)$
is finite. On a leaf $H\in\mathcal L(Q,N)$, the iteration makes at most one
call of $\mathcal B$, which stops within $\tau$ by assumption. The algorithm
splits any other $H$ because $\mathcal B$ did not return within $\tau$, and
stops $\mathcal B$ there. The split then makes one restriction to $x=0$ and
one call of $\Call{Saturate}{}$, which stops within $\tau$ as well, since it
returns $H$ when \texttt{sat} does not finish.

For a pending branch $(Q,Z,N)$, let $d=|Y\setminus(Z\cup N)|$ be the number
of variables it can still split on. A split variable $x$ lies in
$\operatorname{vars}(H)\setminus(Z\cup N)$, so both children of a split have
$d$ one smaller than the pending branch whose iteration creates them. An
iteration therefore removes one element from the multiset of the numbers $d$
over $W$ and adds finitely many smaller ones. This multiset order is well
founded~\cite{dershowitz1979proving}, so the loop makes finitely many
iterations.
\end{proof}
