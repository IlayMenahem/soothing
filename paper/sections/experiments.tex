\section{Experiments}
\label{sec:experiments}

\subsection{Setup}
\label{subsec:experimental-setup}

We implemented Algorithm~\ref{alg:Branching} in Rust 1.97.1 and used
Symbolica 1.5 for polynomial arithmetic over the
rationals~\cite{ruijl2023symbolica}. In all experiments, we solve the branches
with a Gr\"obner-basis computation. The available implementations are M4GB,
F5, GVW, F4, and Singular 4.4.1~\cite{makarim2017m4gb,faugere2002f5,
gao2016gvw,faugere1999f4,singular2025}.
A basis containing $1$ certifies that the branch is UNSAT.
The comparison also includes six direct whole-ideal
Gr\"obner-basis configurations, three decomposition methods from Singular,
Macaulay2 1.26.06, and a numerical method from HomotopyContinuation.jl under
Julia 1.12.6~\cite{singular2025,macaulay2,breiding2018homotopy,
bezanson2017julia}.

For Algorithm~\ref{alg:ZeroingBranching}, we test M4GB, F5, GVW, F4,
and Singular as branch solvers, disable UNSAT-core learning, and impose a
three-second limit on each hitting-set computation.  We selected this cutoff by
trying one, two, three, and five seconds on the hard gated systems.  Three
seconds is the smallest tested value that lets Singular complete the Katsura-8
residual (about 2.6 seconds); five seconds completes no additional hard system
and only delays the subsequent splits.

We ran the benchmark on an Apple M4 Pro with 14 CPU cores and 24 GB of memory.
Every table entry is a single run. Every method received 60 seconds per system;
the three-second variable zeroing limit is an inner, per-hitting-set limit within that budget.

For factor branching and variable zeroing, $T$ is end-to-end wall time and $F$ is the
time to first SAT branch, measured from the start of the
minimal-hitting-set search.  Factorization and input processing are therefore included in
$T$ but not in $F$.
The complete measurements are stored in the appendix.

\subsection{Baseline systems}
\label{subsec:baseline-systems}

The baseline has 20 generated systems in six families.
\begin{itemize}
    \item Signed-distance cycles and affine-factor hypergraphs test many inexpensive hitting sets.
    \item The overlapping random multiples use seeded dense quadratic factors that recur across equations, with no factor shared by every equation.
    \item For gated systems, we create a new variable and multiply every equation in Cyclic, Katsura, or dense quadratic by it~\cite{bjorck1991cyclic,boege1986examples}.
    \item This produces one easy selector hitting set and one nonlinear residual hitting set.
\end{itemize}

% [Theortical explanation of when factor branching and variable zeroing are a good choice]
Factor branching is a good choice when factorization produces branch ideals that are
substantially easier than the expanded input ideal.  A large number of hitting
sets can still be manageable when individual branches are cheap to solve;
the positive affine family shows that the hitting-set count alone is not
decisive.  The method is less effective when one hitting set retains the difficulty
of the original nonlinear system, as Cyclic-7 does.

% [Back up the explanation with current or new experiments]
The measurements of time to first SAT branch support this explanation.  On positive affine
$(12,10,6)$, $F$ rounds to $0.000$ seconds despite the 833 hitting sets.  On
gated Katsura-8, the first SAT branch is found in $0.052$ seconds, but
the full run takes $2.657$ seconds.  Factorization therefore finds the easy
component quickly, while the nonlinear residual controls completion time.

\subsection{Physical System}
\label{subsec:physical-system}

The system is an order-five approximation constraining graviton couplings in
asymptotic-safety models to remain consistent with quantum field theory
(QFT)~\cite{rafiezinedine2018simplifying,vacca2010asymptotic}. Solving this
system helps determine admissible fixed-point structures in quantum
gravity~\cite{vacca2010asymptotic}.

For this larger system, every run, including the standalone baselines, has a
120-second total limit.  Within it, variable zeroing uses a five-second limit per
hitting set; factor branching places no further limit on a hitting set.

All ten standalone baselines time out after 120 seconds on the physical system:
M4GB, F5, GVW, and F4 in grevlex order, Singular and Macaulay2 lex Gr\"obner
bases, Singular \texttt{facstd} and \texttt{primdecGTZ}, Macaulay2
\texttt{decompose}, and HomotopyContinuation.jl.  Factor branching with
\texttt{facstd} completes in 1.341 seconds.  Every backend solves the same 32
of the 33 terminal hitting sets as SAT within 0.13 seconds in total, and times out on
the last one.  Only \texttt{facstd} shows that this hitting set is UNSAT, so
only in hindsight do we know that the 32 SAT branches found by the other
backends already contain every solution.

Variable zeroing also completes with M4GB and Singular, making completion more
robust to backend choice on this system: three of six backends succeed, versus
one with factor branching alone.
