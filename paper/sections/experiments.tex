\section{Experiments}
\label{sec:experiments}

\subsection{Setup}
\label{subsec:experimental-setup}

We implemented Algorithm~\ref{alg:Branching} in Rust 1.97.1 and used
Symbolica 1.5 for polynomial arithmetic over the rationals. In all experiments,
we solve the branches with a Gr\"obner-basis computation. The available
implementations are M4GB, F5, GVW, F4, and Singular 4.4.1.
A basis containing $1$ certifies that the branch is UNSAT.
We obtain an UNSAT core by iterative refinement as in Section 5 of \cite{sun2016}. The comparison also includes six direct whole-ideal
Gr\"obner-basis configurations, three decomposition methods from Singular,
Macaulay2 1.26.06, and a numerical method from HomotopyContinuation.jl under
Julia 1.12.6.

For Algorithm~\ref{alg:ZeroingBranching}, we test M4GB, F5, GVW, Symbolica,
and Singular as branch solvers, disable UNSAT-core learning, and impose a
three-second limit on each cover computation.  We selected this cutoff by
trying one, two, three, and five seconds on the hard gated systems.  Three
seconds is the smallest tested value that lets Singular complete the Katsura-8
residual (about 2.6 seconds); five seconds completes no additional hard system
and only delays the subsequent splits.

We ran the benchmark on an Apple M4 Pro with 14 CPU cores and 24 GB of memory.
Every table entry is a single run. Every method received 60 seconds per system;
the three-second zeroing limit is an inner, per-cover limit within that budget.

For branching and variable zeroing, $T$ is end-to-end wall time and $F$ is the
time from the start of the minimal-hitting-set search to its first satisfiable
hitting set.  Factorization and input processing are therefore included in
$T$ but not in $F$.
The complete measurements are stored in the appendix.

\subsection{Baseline systems}
\label{subsec:baseline-systems}

The baseline has 20 generated systems in six families.
\begin{itemize}
    \item Signed-distance cycles and affine-factor hypergraphs test many inexpensive hitting sets.
    \item The overlapping random multiples use seeded dense quadratic factors that recur across equations, with no factor shared by every equation.
    \item For gated systems, we create a new variable and multiply every equation in Cyclic, Katsura, or dense quadratic by it.
    \item This produces one easy selector cover and one nonlinear residual cover.
\end{itemize}

% [Theortical explanation of when branching and variable zeroing are a good choice]

Branching is a good choice when factorization produces branch ideals that are
substantially easier than the expanded input ideal.  A large number of hitting
sets can still be manageable when branch solving and core checks are cheap;
the positive affine family shows that the hitting-set count alone is not
decisive.  The method is less effective when one cover retains the difficulty
of the original nonlinear system, as Cyclic-7 does.

% [Back up the explanation with current or new experiments]

The first-solution measurements support this explanation.  On positive affine
$(12,10,6)$, $F$ rounds to $0.000$ seconds despite the 833 hitting sets.  On
gated Katsura-8, the first satisfiable cover appears in $0.052$ seconds, but
the full run takes $2.657$ seconds.  Factorization therefore finds the easy
component quickly, while the nonlinear residual controls completion time.

% [Variable zeroing analysis]
Variable zeroing is intended for a narrower case: a cover has timed out, but
branching a variable to zero or nonzero, both simplify it the system.
The current benchmark gives limited evidence for that mechanism because none of the completed zeroing runs requires a split.
On Cyclic-7, zeroing continues the stalled search and returns a partial result,
but it does not complete the residual branch.


\subsection{Physical Systems}
\label{subsec:physical-systems}

% A short explanation of the physical systems.
The system is an order five approximation of the theories that represent a graviton are consistent with experimental results of QFT (quantum field theory).
Solving this system can lead to a better understanding of how quantum gravity may look like.

In the table we note that we get a complete solution when using facstd as the backend, and we get a complete solution when using either branching or zeroing.
When using any backend with zeroing we get a partial solution, while branching with branching some backends don't find any solutions.
None of the other benchmarked methods is able to solve the system within 10 minutes, not even partial solutions.
