\subsection{Variable zeroing}

completed variable zeroing configuration evaluated across the baseline suite;
where no configuration completes, it gives the partial run with the fewest
unresolved branches.
Every backend receives three seconds per branch and a 60-second outer budget.
The overlapping-random-multiple and positive affine rows disable interreduction, as in the
factor branching experiment.  Here $N$ is the number of recursion nodes,
$E$ the number of hitting-set evaluations, $O/S$ the numbers of per-branch timeouts
and variable zeroing splits, and $C/U$ the numbers of returned components and unresolved
branches.  The time entry is $T/F$.

root system exceeds the three-second per-branch limit, so no hitting set is
evaluated.  With a 60-second per-branch limit this refinement finishes; for example,
signed distance $n=10$ refines to 252 hitting sets in 4.06 seconds and square
affine $(10,5)$ to 681 in 9.05 seconds.
